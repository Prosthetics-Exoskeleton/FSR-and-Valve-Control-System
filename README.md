# Exoskeleton Team Code
ESP32 code to run FSR/Valve control system for pneumatic grip exoskeleton.

## Steps to compile
Install VSCode: https://code.visualstudio.com/download

Install C++ for VSCode: https://code.visualstudio.com/docs/languages/cpp

Install PlatformIO in VSCode: https://platformio.org/install/ide?install=vscode

Pull this repo, then open project in platformIO, navigate to the repo folder, and open.
